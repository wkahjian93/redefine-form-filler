# REDEFINE Form Filler

Installable team app that fills blank forms from customer files.

- `app/app.html`: the page. `app/shim.js`: its connection to the team server.
- `server/Code.gs`: Google Apps Script team server. See `SETUP TEAM SERVER.md`.
- `node build.js` writes `docs/`, which GitHub Pages serves.

This repository is public. API keys, team codes and client data never go here.
